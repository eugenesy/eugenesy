### Research

**PRISM-CI: screening for cognitive impairment from a recorded memory test.** Acoustic, facial and audio-visual features from older adults recalling a word list, with no transcript needed. Held-out AUROC 0.761 on 276 participants. First author; under review at IEEE JBHI.

**GAP-TGN: detecting information channels in U.S. congressional trading.** A temporal graph network linking congressional stock trades to lobbying, campaign finance and committee data, plus Capitol Gains, a point-in-time dataset for 2013–2025. Co-first author; ICLR 2026 Workshop on Advances in Financial AI. [arXiv](https://arxiv.org/abs/2602.05514) · [OpenReview](https://openreview.net/forum?id=j4qda5FRYq)

**On-device language assistant.** At AUO Mobility Solutions, replaced a rule-based command dispatcher with an LLM tool-calling backend for an edge hardware product, cutting end-to-end response time from 7–10 s to 2–3 s.

**Argument mining in financial text.** BERT-family ensembles that placed 1st in argument unit identification at NTCIR-17 FinArg-1; the 2025 journal version reached 77.08% macro-F1. [Paper](https://aclanthology.org/2023.rocling-1.30/) · [Code](https://github.com/nlptmu/FinArg-1_AUC_FinSeq)
